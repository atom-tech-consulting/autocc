# tb

Alias for `/taskboard`. See the [`taskboard`](../taskboard/SKILL.md) skill for the full reference.

All arguments are passed through:

- `/tb` → `/taskboard` (show status)
- `/tb init` → `/taskboard init`
- `/tb prep TB-5` → `/taskboard prep TB-5`
- `/tb brief TB-5` → `/taskboard brief TB-5`
